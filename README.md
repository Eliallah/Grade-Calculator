# C++ Grade-Calculator

This project allows users to calculate their final course grade based on points earned across various categories, including programming assignments, midterms, Pearson points, and the final programming assignment. Users enter their scores, and the program calculates the final percentage and assigns a letter grade according to predefined criteria. It also offers the option to include extra credit points, enhancing the accuracy of the grade calculation. The code includes error checking for valid input and adheres to the provided grading formula, providing a practical tool for students to assess their course performance.
